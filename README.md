# A Day of One-Line Pitches

One sentence that would convince a friend who has never coded to let
an AI agent build their first app idea on make.fun.

> That app idea you keep mentioning? Describe it to an AI agent on make.fun and it builds a real first version for free — no code from you, no risk, just your idea coming to life.

## Run

```sh
python3 main.py
```

Writes the pitch to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`). Standard library only, deterministic, no network.
